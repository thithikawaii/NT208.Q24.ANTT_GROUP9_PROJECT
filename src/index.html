CI/CD

Deploy & rollback

Workflow có build image, deploy staging và rollback.

Pipeline

Điểm liên kết với DevOps

  1. A

    Push lên develop

    GitHub Actions chạy scan, test, build và push Docker image.

  2. B

    Deploy staging

    EC2 kéo image mới bằng tag commit và chạy bằng Docker Compose.

  3. C

    Rollback khi lỗi

    Nếu smoke test thất bại, pipeline đổi lại tag trước đó và chạy lại container.
